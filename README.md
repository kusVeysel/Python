# SummerPy Python Dersleri

Bu klasör, Python'un temel sözdiziminden modüllere ve nesne yönelimli programlamaya
uzanan örneklerden oluşur. Dosyaları numara sırasıyla incelemek önerilir.

## Temel bilgiler

- Python dinamik ve güçlü tipli bir dildir. Değişkenler belirli bir tipe kilitlenmez,
	ancak her değer bir tipe sahiptir.
- Girintileme blok yapısının parçasıdır; her boşluk zorunlu değildir fakat aynı blokta
	tutarlı girinti kullanılmalıdır.
- Tek satırlık yorum `#` ile yazılır. Üç tırnaklı metinler yorum değil, string
	literal'dır; fonksiyon veya sınıfın ilk ifadesi olduklarında docstring olabilirler.

## Çalıştırma

Python 3.11 veya daha yeni bir sürümle bir dosyayı çalıştırabilirsiniz:

```text
python 01-Giris.py
```

Bazı dosyalar `input()` kullanır ve çalışırken kullanıcı girdisi bekler. Örnekler
bağımsızdır; bir dosyada tanımlanan değişkenler diğer dosyaya otomatik aktarılmaz.
